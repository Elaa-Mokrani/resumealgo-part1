1Comprendre l’essentiel

Programme console

Le programme décide de l’ordre : il demande, attend la réponse, calcule, affiche. L’utilisateur répond au clavier, en mode texte.

n = int(input("n : "))
print(n * 2)

Programme graphique (GUI)

L’utilisateur décide : il clique quand il veut, sur le bouton qu’il veut. Le programme attend puis réagit : c’est la programmation évènementielle.

GUI = Graphical User Interface (interface graphique).

Code Python
from PyQt5 import QtWidgets, uic

app = QtWidgets.QApplication([])
dlg = uic.loadUi("interface_somme.ui")

def somme(n1, n2):
    return n1 + n2

def calcul():
    ch1 = dlg.a.text()              # une saisie est toujours une chaîne
    ch2 = dlg.b.text()
    if ch1.isdigit() and ch2.isdigit():
        r = somme(int(ch1), int(ch2))   # conversion str -> int
        dlg.resultat.setText(str(r))    # conversion int -> str
    else:
        dlg.resultat.setText("ERREUR DE SAISIE")

# Connexions
dlg.calculersomme.clicked.connect(calcul)

dlg.show()
app.exec()
Remarque. isdigit() n’accepte que les entiers positifs. Pour accepter les négatifs, on peut tester la conversion avec try / except.

from PyQt5 import QtWidgets, uic

app = QtWidgets.QApplication([])
dlg = uic.loadUi("int_pgcd.ui")

def pgcd(a, b):
    while a != b:
        if a > b:
            a = a - b
        else:
            b = b - a
    return a

def calcul_pgcd():

Procédure reinit() : vider n et res, curseur dans n
Code Python
from PyQt5 import QtWidgets, uic

app = QtWidgets.QApplication([])
dlg = uic.loadUi("int_premier.ui")

def premier(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n and n % i != 0:
        i = i + 1
    return i * i > n

def tester():
    ch = dlg.n.text()
    if not ch.isdigit():
        dlg.res.setText("ERREUR DE SAISIE")
    elif premier(int(ch)):
        dlg.res.setText(ch + " est un nombre premier")
    else:
        dlg.res.setText(ch + " n'est pas un nombre premier")

def reinit():
    dlg.n.clear()
    dlg.res.clear()
    dlg.n.setFocus()

# Connexions
dlg.tester.clicked.connect(tester)
dlg.init.clicked.connect(reinit)
dlg.fermer.clicked.connect(dlg.close)   # close sans parenthèses

dlg.show()
app.exec()
Pourquoi i * i ≤ n ? Si n a un diviseur, il en a un inférieur ou égal à √n : inutile de tester au-delà. Attention : dans le cours, la condition i < n//2 déclare à tort 4 premier ; ici elle est corrigée.

Code Python
from PyQt5 import QtWidgets, uic

app = QtWidgets.QApplication([])
dlg = uic.loadUi("mini_cal.ui")

def calculer():
    ch1 = dlg.n1.text()
    ch2 = dlg.n2.text()
    op = dlg.op.currentText()            # choix de la liste déroulante
    if not (ch1.isdigit() and ch2.isdigit()):
        QtWidgets.QMessageBox.critical(dlg, "Attention", "entrer deux entiers")
    else:
        x = int(ch1)
        y = int(ch2)
        if y == 0 and op in ["/", "div", "mod"]:
            QtWidgets.QMessageBox.critical(dlg, "Attention", "division par zéro")
        else:
            if op == "+":
                r = x + y
            elif op == "-":
                r = x - y
            elif op == "*":
                r = x * y
            elif op == "/":
                r = x / y
            elif op == "div":
                r = x // y
            else:
                r = x % y
            dlg.res.setText(str(r))

# Connexions
dlg.btn_egal.clicked.connect(calculer)

dlg.show()
app.exec()

Code Python : version 5 (Combo Box)
from PyQt5 import QtWidgets, uic

app = QtWidgets.QApplication([])
dlg = uic.loadUi("int_pgcd_ppcm.ui")

def pgcd(a, b):
    while a != b:
        if a > b:
            a = a - b
        else:
            b = b - a
    return a

def ppcm(a, b):
    return a * b // pgcd(a, b)

def saisie_valide(ch1, ch2):
    return ch1.isdigit() and ch2.isdigit() and int(ch1) > 0 and int(ch2) > 0

def calcul():
    ch1 = dlg.n1.text()
    ch2 = dlg.n2.text()
    if not saisie_valide(ch1, ch2):
        QtWidgets.QMessageBox.critical(dlg, "Attention", "entrer des entiers strictement positifs")
    else:
        a = int(ch1)
        b = int(ch2)
        if dlg.op.currentText() == "PGCD":
            r = pgcd(a, b)
        else:
            r = ppcm(a, b)
        dlg.res.setText(str(r))

# Connexions
dlg.calculer.clicked.connect(calcul)
dlg.fermer.clicked.connect(dlg.close)

dlg.show()
app.exec()

Qt Designer (.ui), puis Thonny (.py), puis loadUi.

Événement

Un clic produit un signal, relié par connect() à un slot (fonction).

Squelette

QApplication, loadUi, fonctions, connect, show, exec().

Saisie

text() donne une chaîne : int() avant calcul, str() avant affichage.

Choix

Combo Box : currentText(). Radio et cases : isChecked().

Validation

Toujours tester la saisie avant de calculer, sinon message d’erreur.
